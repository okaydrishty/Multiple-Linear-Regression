# Multiple-Linear-Regression
## Project Overview
This project performs multiple linear regression using the Possum dataset to predict the variable totlngth (total length of the possum) based on several physical attributes.
## Objective
To build a multiple linear regression model using scikit-learn to predict totlngth based on other features.
## Model Used
- **Algorithm:** `LinearRegression` from scikit-learn  
- **Type:** Supervised learning (Regression)  
- **Goal:** Predict continuous numeric output 
## Evaluation Metrics
Mean Squared Error (MSE)
R² Score (Coefficient of Determination)
